# ─── DETERMINISM ──────────────────────────────────────────────────────────────
# The engine is deterministic: same input, byte-identical report. To verify:
#
#   cd brand-ai-readiness-audit
#   python3 tests/run_offline.py
#   # -> "PASS: offline, deterministic, goldens current, control clean."
#
# That replays six fixture sites against checked-in golden reports byte-for-byte
# and re-runs two of them across a TZ x PYTHONHASHSEED matrix.
#
# On a live URL, reports differ between runs only where the SITE changed or the
# crawl sampled different pages; audited_at is the only field that always moves.

# ─── WHAT THE ENGINE WILL AND WILL NOT DO ─────────────────────────────────────
# Read-only. The HTTP layer validates every method against a {GET, HEAD}
# allowlist, so no code path can alter the audited site. robots.txt is a hard
# constraint on crawling, not advice. No cookies, credentials or authenticated
# areas. Hosts resolving to private/loopback/link-local space are refused on the
# seed and on every redirect hop. The whole run is bounded by --time-budget
# (default 300s).
#
# Two checks are OFF by default and report "not assessed" rather than passing:
# CDN/WAF reachability for named AI crawlers needs --probe-bot-ua, because
# sending named-crawler user-agents at a site you do not own is not something an
# audit should do unless asked. Add that flag only for a site you control.
